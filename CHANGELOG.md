# Changelog

All notable changes to the WAVES artifact are recorded here. The version in
`VERSION` follows semantic versioning; the data and the code are versioned together.

## [0.1.0] - 2026-10-12

Initial scaffold of the paper artifact.

- 475 workflows: 465 real-world snapshots and 10 synthetic CFW workflows.
- 2,424 evidence-linked weakness labels over 467 workflows; 8 confirmed all-negative workflows.
- 445 reference decisions (100-workflow reference subset) and 2,136 helper candidates
  (1,969 accepted, 167 rejected) over the 365 helper-reviewed workflows.
- Inventories for KVCW and GRCW, validation script and reproduction scripts.
